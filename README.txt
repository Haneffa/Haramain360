HARAMAIN360 — Indonesia Edition (prototipe)

Buka index.html melalui server web lokal atau hosting statis (GitHub Pages/Netlify).
Bahasa utama: Bahasa Indonesia. Mata uang perencanaan: IDR (Rp).
Akun demo: HARAMAIN360001 / Umrah2026 (lihat kartu login untuk detail yang sesuai).

PERINGATAN: Seluruh nilai uang dalam demo merupakan ilustrasi, bukan hasil konversi kurs resmi. Tidak ada penyimpanan emas, perdagangan emas, verifikasi izin perjalanan secara langsung, atau transaksi keuangan. Data dan paket perjalanan perlu diganti sumber resmi Indonesia sebelum dipublikasikan sebagai produk pemerintah.
Login hanya demo front-end, bukan autentikasi aman. Jangan masukkan data pribadi asli.
Beberapa fitur menggunakan internet (font, peta, A-Frame, kurs).
